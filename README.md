# NeuroAiR: Deep Learning Framework for Airwriting Recognition From Scalp-Recorded Neural Signals

Implementation of the paper "NeuroAiR: Deep Learning Framework for Airwriting Recognition From Scalp-Recorded Neural Signals" ([https://ieeexplore.ieee.org/abstract/document/10050548](https://ieeexplore.ieee.org/abstract/document/10478979))

The dataset corresponding to this paper can be accessed at [https://drive.google.com/file/d/1jmSGnliDueGzXI8muPez8Bfs2c9D0t_E/view?usp=sharing
](https://drive.google.com/drive/folders/1FSv7qUqWI832zTQfPvgczpl_-eIyyOCy?usp=sharing)

If you are using the dataset for publication purposes, the paper "NeuroAiR: Deep Learning Framework for Airwriting Recognition From Scalp-Recorded Neural Signals" ([https://ieeexplore.ieee.org/abstract/document/10050548](https://ieeexplore.ieee.org/abstract/document/10478979)) must be cited.
